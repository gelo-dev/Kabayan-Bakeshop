# Kabayan Bakeshop

A modern and responsive **Bakeshop website** built with **React** and **Tailwind CSS**, designed to showcase products, menus, and community features. Perfect for small businesses looking to establish an online presence.

## Demo

Live site: [https://kabayans-bakeshop.netlify.app/](https://kabayans-bakeshop.netlify.app/)

## Features

- Responsive design for mobile and desktop  
- Product gallery and featured items  
- Smooth horizontal scrolling for product sections  
- Community/testimonial section  
- Built with **React** and **Tailwind CSS**  
- Optional backend integration with Node.js & MySQL  

## Tech Stack

- **Frontend:** React, Tailwind CSS  
- **Backend (optional):** Node.js, Express, MySQL  
- **Deployment:** Vercel / Netlify  
- **Design Tools:** Adobe Illustrator, Photoshop  

## Installation

1. Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/kabayan-bakeshop.git
```
2.Navigate to the project folder:
```bash
cd kabayan-bakeshop
```
3.Install dependencies:
```bash
npm install
```
4.Run the development server:
```bash
npm run dev
```
5.Open http://localhost:3000 in your browser.
